# Meet Cute

A small Tinder-inspired dating website prototype built with Java, Spring Boot, and plain HTML/CSS/JavaScript.

## Run locally

```bash
mvn spring-boot:run
```

Then open [http://localhost:8080](http://localhost:8080).

The app includes a profile discovery screen, like/pass/rewind controls, keyboard arrows, and a demo match. Profiles and swipe responses are in memory; authentication, real mutual matching, chat, and database persistence are not implemented.
